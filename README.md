#### 项目

**[CheryStage](https://github.com/CherySui/CheryStage)**：一站式 MMD 工作流 Blender 插件
- 关键帧缓动库：36 种可视化缓动预设，曲线编辑器、动画摄影表、3D 视图通用
- MMD 物理烘焙：外置 MMD 式 Bullet 物理，结果直接写成关键帧；7000 帧约 50 秒，比 Blender 刚体快约 30 倍
- 渲染导出：视频 / 序列帧、帧率时间拉伸、透明背景保留辉光
- 安装：Blender 偏好设置 → 获取扩展 → 添加远程存储库 `https://cherysui.github.io/CheryStage/index.json`，之后自动提示更新

**[CheryTools](https://github.com/adofaiex/CheryTools)**：《冰与火之舞》（ADOFAI）综合辅助模组
- KeyViewer：可视化拖拽编辑按键显示，按键雨、KPS、图片 / 视频键
- Overlayer：文本、图片、视频、进度条组件，实时标签与节点动画
- AET Recorder：把谱面离线渲染成视频，支持 x264 / x265 / NVIDIA 硬件编码

**CheryEditor**：仿 Pr 界面、Rust 内核的剪辑软件

**CheryLauncher**：多功能米哈游启动器
